Yfit OS live session

This live desktop runs as the unprivileged account yfit. The account password is created randomly for each live boot and is available only to that account at /run/yfit-live-admin-password. It is not built into the ISO. Installed accounts and passwords are created in the installer.

Hardware support depends on firmware and kernel drivers shipped in Debian 13. Secure Boot signing, NVIDIA proprietary drivers, fingerprint readers, and vendor-specific laptop controls are not guaranteed. See the release documentation for the support policy.
