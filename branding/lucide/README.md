# Lucide assets

These SVGs are copied from the official Lucide icon set and bundled under its MIT license (see `LICENSE`). The installed Yfit icon theme uses Lucide-derived files for generic system actions such as display, wireless, audio, storage, firewall, and power. Third-party application desktop-file icons are left intact. `installed-aliases/` retains unused alias candidates that were deliberately not installed over upstream app icons.
