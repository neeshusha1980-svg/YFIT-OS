# Fredoka font asset

`Fredoka-VF.ttf` is the variable Fredoka font from the Google Fonts repository (`ofl/fredoka/Fredoka[wdth,wght].ttf`). It is bundled in the chroot under `/usr/share/fonts/truetype/yfit/` and selected as the GTK/XFCE UI font. The upstream SIL Open Font License 1.1 is included as `OFL-Fredoka.txt` and copied into the installed documentation. The current vendored file SHA256 is `2ba02e68b152868aef9ba28e24b3648c7d457fe6f25c761f2c2c53fb61a73fc8`.
